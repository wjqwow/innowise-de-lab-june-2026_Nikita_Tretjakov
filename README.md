# innowise-de-lab-june-2026\_Nikita\_Tretjakov



ECOMARKET - проект, созданный для моделирования работы сети продуктовых магазинов, который специализируется на продаже экологически чистых фермерских товаров. Проект помогает компании анализировать продажи, клиентов, сотрудников и категории товаров.



Цель - построить учебную платформу, которая объединяет данные из CSV-файлов и демонстрирует полный цикл работы с данными.



Источники данных:

sales.csv

customers.csv

products.csv

employees.csv

cities.csv

countries.csv

shops.csv



Автор проекта - Никита Третьяков
